# heart-animation-for-14th-february

Небольшая веб-страница с анимацией сердца ко Дню святого Валентина. Flask отдаёт два HTML-шаблона: с текстом и без него.

## Запуск

```sh
python -m pip install flask
python main.py
```

- `http://localhost:8080/love-with-compliments` — версия с текстом.
- `http://localhost:8080/love-with-emojis` — альтернативная версия.
